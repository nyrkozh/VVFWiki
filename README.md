# VVFWiki — обучающая вики для программистов

Код сверху, визуализация снизу. Разделы создаются в админке; пользователи предлагают статьи в нужный раздел.

## Запуск

Нужен только Node.js (без npm):

```bash
node server.mjs
```

Админ-панель (**/admin.html**) защищена логином и паролем.  
Учётные данные хранятся в `data/admins.json` (пароль — в виде хеша scrypt).

## Где хранятся изменения

Разделы и статьи сохраняются в **`data/sections.json`** и **`data/articles.json`** на диске (эти файлы в Git не попадают).

Шаблоны для первого запуска лежат в `data/seed/`. При `git pull` или деплое с GitHub ваши правки **не сбрасываются**, если не удалять папку `data/` на сервере.

**Почему могли пропадать изменения раньше:** старые версии `sections.json` / `articles.json` были в репозитории — при обновлении кода Git подменял их демо-данными.

**OneDrive / Рабочий стол:** если проект в синхронизируемой папке, облако иногда откатывает JSON. Надёжнее держать сайт в `C:\Projects\VVFWiki` и не открывать `data/*.json` в редакторе во время работы админки.

Резервные копии при каждом сохранении: `data/backups/`.

## Возможности

| Страница | Назначение |
|----------|------------|
| `/` | Список разделов |
| `/section.html?slug=...` | Статьи раздела + кнопка «Предложить статью» |
| `/article.html?slug=...` | Статья: блоки кода + интерактивная визуализация |
| `/submit.html` | Форма предложения статьи (статус `pending`) |
| `/admin.html` | Вход администратора, разделы, модерация |

## Формат статьи

Каждая статья состоит из **блоков**. Блок = заголовок + код + пояснение + JSON визуализации.

Типы визуализации:

- **array** — исходный массив → функция → результат
- **variables** — таблица переменных по шагам (кнопки «Далее»)
- **console** — построчный вывод в консоль
- **steps** — пошаговое изменение массива (filter/map и т.п.)

Пример JSON для блока:

```json
{
  "type": "array",
  "input": [1, 2, 3],
  "output": [2, 4, 6],
  "label": "n => n * 2",
  "highlightIndex": 1
}
```

Данные хранятся в `data/sections.json` и `data/articles.json`.
