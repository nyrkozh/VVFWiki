# DevWiki — обучающая вики для программистов

Код сверху, визуализация снизу. Разделы создаются в админке; пользователи предлагают статьи в нужный раздел.

## Запуск

Нужен только Node.js (без npm):

```bash
node server.mjs
```

Откройте в браузере: **http://localhost:3847**

Админ-панель (**/admin.html**) защищена логином и паролем.  
Учётные данные хранятся в `data/admins.json` (пароль — в виде хеша scrypt).

## Возможности

| Страница | Назначение |
|----------|------------|
| `/` | Список разделов |
| `/section.html?slug=...` | Статьи раздела + кнопка «Предложить статью» |
| `/article.html?slug=...` | Статья: блоки кода + интерактивная визуализация |
| `/submit.html` | Форма предложения статьи (статус `pending`) |
| `/admin.html` | Вход администратора, разделы, модерация |

## Формат статьи

Каждая статья состоит из **блоков**. Блок = заголовок + код + пояснение + JSON визуализации.

Типы визуализации:

- **array** — исходный массив → функция → результат
- **variables** — таблица переменных по шагам (кнопки «Далее»)
- **console** — построчный вывод в консоль
- **steps** — пошаговое изменение массива (filter/map и т.п.)

Пример JSON для блока:

```json
{
  "type": "array",
  "input": [1, 2, 3],
  "output": [2, 4, 6],
  "label": "n => n * 2",
  "highlightIndex": 1
}
```

Данные хранятся в `data/sections.json` и `data/articles.json`.
